# public/app — клиентские модули

Точка входа: `main.js` (ESM; порядок импортов = порядок инициализации, `boot.js` последний).
Каноническая карта «модуль → часть сайта»: `../../docs/module-map.md`.
CSS по слоям: `../../docs/css-architecture.md`. Барьеры CI: `../../docs/guardrails.md`.

Базовые правила:
- Один DOM-узел — один модуль-владелец (см. карту владения).
- Межмодульное взаимодействие — только через window.*-контракты из карты.
- Новый модуль → обновить `docs/module-map.md` тем же PR.
