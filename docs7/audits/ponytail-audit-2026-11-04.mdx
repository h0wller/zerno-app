## Strict jscpd findings

The strict run reported five clone pairs. They are not all equivalent abstractions.

| Clone pair | Disposition | Reason |
|---|---|---|
| `public/app/core/auth.js`: account deletion vs logout | Keep separate | Deletion invokes `DELETE /api/me`, attempts native push unsubscribe best-effort, and aborts UI cleanup with an error on server failure. Logout posts `/push/unsubscribe` where a subscription exists, calls `/exit`, then clears the local session. These are different lifecycle and failure contracts. |
| `public/app/profile-orders.js` vs `public/app/ui/settings.js`: Tab focus trap | Defer shared helper | The core wrap logic is similar, but the orders modal and settings modal have separate open/close, nested order-tracker and focus-restoration behavior. A shared helper is reasonable only as a separate accessibility refactor with keyboard/focus E2E coverage for both modal lifecycles. |
| `server/routes/auth.js`: Telegram-link registration vs normal registration | Keep separate | The former starts from a Telegram-confirmed number, links immediately, sets consent, issues the welcome grant and QR-aware bonus. The latter can be SMS/Telegram OTP or unverified activation-code flow; it has additional token cleanup when linking fails and different verification branches. |
| `server/routes/auth.js` vs `server/routes/tg.js`: Telegram registration | Keep separate | Mini App link flow and bot-contact verification run in different trust/event contexts. The former accepts a QR source and can grant the QR bonus; the bot contact flow derives identity from the verified contact and grants signup bonus. Their token and failure handling are not interchangeable. |
| `server/routes/auth.js`: profile update vs notification update | Keep separate | They update different columns and have different route contracts. The common database-update/response shape is not enough to justify a helper. |

The clone count intentionally remains non-zero. Do not silence `jscpd` or mechanically deduplicate these paths merely to reach zero.
