## Исторический контекст

Исходный аудит описывал разросшийся inline CSS в `public/index.html`, дубли шапки и рейла, а также план переноса в `theme-v2.css`. Эта архитектура и файл сборки `theme-v2.css` больше не являются актуальной моделью проекта. Позднейшие изменения сформировали четыре логических слоя CSS, где 2a/2b — подслои брендового слоя.

Не переносить незакрытые пункты из старого аудита в текущий backlog без повторной проверки исходников и computed styles.

## Текущая модель

См. единственный нормативный источник: [CSS architecture](./css-architecture.md).

- Слой 1: `public/app/ui/theme/*.css`.
- Слой 2a: `public/app/ui/brand-tokens.css`.
- Слой 2b: `public/app/core/views.js`.
- Слой 3: локальные стили компонентных модулей.
- Слой 4: минимальный critical CSS в `public/index.html`.

## Дальнейший triage

Для каждого старого finding:
1. Найти текущий selector и все места определения.
2. Сверить media context, specificity, порядок stylesheet и брендовые условия.
3. Проверить first paint, hydrated DOM и оба бренда.
4. Сравнить CSS audit, скриншоты и реальную computed geometry.
5. Зафиксировать disposition: fixed, still valid, accepted, superseded или needs evidence.

Не устранять повтор селектора автоматически: одинаковый selector может быть намеренным fallback/override. Не использовать отсутствие предупреждений CSS audit как доказательство полного отсутствия каскадных проблем.

## Статус

В этом обновлении архитектурная терминология и ссылки на удалённый `theme-v2.css` исправлены. Полный повторный визуальный аудит всех исторических CSS findings ещё не выполнен; конкретные незакрытые дефекты здесь не объявляются.
