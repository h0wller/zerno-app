# Архитектурное правило: ADR-008 — Детерминированная реактивность DOM

Контекст:

Использование глобальных MutationObserver с таргетом document.body или глубоким деревом (subtree: true) приводит к каскадному Layout Thrashing, гонкам рендеринга и непредсказуемой деградации FPS на мобильных устройствах (PWA / Telegram WebApp).

Нормативные требования:

Полный запрет на document.body как цель наблюдения:

Запрещено передавать document.body или document.documentElement в .observe().

Наблюдение разрешено исключительно за изолированными листовыми контейнерами (например, конкретная шторка #panel).

Обязательное самоотключение (Self-Disconnecting):

Любой одноразовый обсервер (подсказки, нормализация сторонней разметки, ожидание первичного рендера) обязан вызывать observer.disconnect() сразу после выполнения целевого действия.

Если условие уже выполнено на момент инициализации (например, флаг в sessionStorage), обсервер не должен создаваться вовсе.

Принцип «Event-First / Direct Invocation»:

Изменение состояния интерфейса должно управляться явным вызовом функции или события (CustomEvent), а не реакцией на случайную мутацию DOM.

При динамической подгрузке данных (например, api('/orders/mine')) синхронизация зависимых представлений вызывается напрямую в конце цепочки await.

Снятие слушателей при демонтировании:

Долгоживущие обсерверы допускаются только для компонентов с собственным жизненным циклом и обязаны отключаться при уничтожении контейнера.
