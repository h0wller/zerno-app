# Заметки на будущее

## Исторически реализованные возможности

### Предзаказы вне рабочего времени — реализовано

- Вне периода доступности ASAP интерфейс предлагает выбрать доступный слот предзаказа.
- Серверная валидация, busy-slot проверки и сохранение preorder-полей описаны в текущей реализации и тестах.
- Диспетчер получает дату/слот предзаказа в карточке заказа.

Не возвращать эту возможность в активный backlog без нового подтверждённого дефекта. Перед изменением поведения сверяться с `docs/frontend-todo.md`, delivery route tests и `docs/openapi.yaml`.

## Активные заметки

Новые продуктовые идеи добавлять сюда только после проверки, что задача не реализована в текущей ветке. Для каждой записи указывать статус (proposed / accepted / in progress / done / won't fix), owner и ссылку на тест или PR. Эта страница не заменяет roadmap и не должна дублировать выполненные milestones.
