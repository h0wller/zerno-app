## Лист ожидания (предзаказы вне рабочего времени)
- При попытке оформить заказ вне 11:00-22:00 показывать модалку:
  - «Сейчас мы не работаем, но можем принять предзаказ»
  - Выбор даты: завтра / послезавтра /
  - Выбор слота: утро (11:00-14:00) / день (14:00-18:00) / вечер (18:00-22:00)
  - Подтверждение: «Заказ будет готов к [дата] в [слот]»
- Бэкенд: добавить поле `preorder_date` в `orders`, флаг `is_preorder`
- UI: отдельная вкладка «Предзаказы» в профиле
- Приоритет: средний
