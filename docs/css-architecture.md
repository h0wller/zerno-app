# CSS-архитектура «…и кофе × Пятница»

## 4 слоя (порядок загрузки = порядок приоритета при равной специфичности)

### СЛОЙ 1 — `public/app/ui/theme-v2.css` (БАЗА)
- Базовые стили компонентов: карточки, кнопки, инпуты, модалки, рейлы, чипсы.
- CSS-переменные бренда «кофейня» в `:root` (дефолт).
- Семантические токены статусов: `--status-*`, `--tint-*`.
- ЗАПРЕЩЕНО: `!important`, хардкод брендовых цветов (`#B4552D`, `#F3E2CE`),
  селекторы `[data-brand=...]` (кроме нейтральных фоновых правок body).

### СЛОЙ 2 — `public/app/core/views.js` (инжекция: layout + бренд)
- Layout-фиксы шапки/сеток/шторки (media-запросы, safe-area).
- Брендовые переопределения ТОЛЬКО через `[data-brand="delivery"] ...`.
- Переключение токенов: `html[data-brand="delivery"], body[data-brand="delivery"] { --flame:...; --esp:...; }`.
- `!important` разрешён ТОЛЬКО здесь и только для перебивки inline-стилей ядра.

### СЛОЙ 3 — компонентные модули (`delivery.js`, `cart.js`, `chat.js`, …)
- Состояния и анимации компонента: `.cta.added`, `.incart`, `@keyframes`.
- Инжекция `createElement('style')` внутри модуля, рядом с логикой.
- Цвета — только через `var(--...)`, без хардкода.

### СЛОЙ 4 — `public/index.html` (CRITICAL)
- Только above-the-fold: splash-фон, `body{margin:0}`, базовая сетка `.wrap`.
- Компонентные стили здесь ЗАПРЕЩЕНЫ.

## Правила добавления стиля (чеклист)
1. Это база компонента? → СЛОЙ 1.
2. Это «в режиме Пятницы выглядит иначе»? → СЛОЙ 2, селектор `[data-brand="delivery"]`.
3. Это состояние/анимация конкретного модуля? → СЛОЙ 3 в этом модуле.
4. Это critical для первой отрисовки? → СЛОЙ 4.
5. Ни в один слой не попал — не пиши стиль, сначала дополни документ.

## Запреты
- Дублировать один селектор в двух слоях (аудит: `grep -n "<селектор>" public/app/ui/theme-v2.css public/app/core/views.js public/index.html`).
- Monkey-patch стилей из компонентных модулей (править базу/бренд можно только в своих слоях).
- Новые `!important` в СЛОЕ 1 и СЛОЕ 3.
- Хардкод цветов брендов вне СЛОЯ 2.
