# Локальное тестирование ролей сотрудников

Эта ветка предназначена только для локальной проверки PR #75. Она не должна мержиться или развёртываться.

## Включение

1. Остановить локальный сервер.
2. Скопировать локальную SQLite-БД в отдельный файл, например `zerno-role-test.db`.
3. В локальном `.env` указать:

```dotenv
DB_PATH=./zerno-role-test.db
LOCAL_ROLE_TESTING=1
```

Если переменная `DB_PATH` уже есть, заменить её значение, а не добавлять вторую строку. Файл `.env` не коммитить.

4. Запустить `npm run build:client`, затем локальный сервер.
5. Войти своим администратором. В правом нижнем углу появится панель тестирования ролей.

## Роли

Переключатель создаёт отдельные профили с backend-ролями `guest`, `cashier` и `dispatch`, повторно используя их при следующих переключениях. Текущий администраторский токен сохраняется в `sessionStorage`; кнопка возврата восстанавливает исходный аккаунт.

Endpoint регистрируется только при `LOCAL_ROLE_TESTING=1`. Без этого флага переключатель не работает. Не добавлять этот флаг в production-окружение и не использовать production-БД.

Профили проходят настоящую серверную авторизацию. Их операции и записи сохраняются в выбранной тестовой БД.
