# Оценочный калькулятор КБЖУ по ТТК

## Назначение и статус

Калькулятор показывает ориентировочную пищевую ценность, а не лабораторный анализ и не подтверждённую маркировку. Весовые составы блюд и выходы взяты из ТТК, переданных владельцем проекта. Показатели ингредиентов на 100 г — усреднённые справочные значения, подобранные по общим продуктам, а не по конкретным маркам поставщиков.

Текущие значения — предварительные справочные оценки, а не точная выгрузка из конкретного набора USDA. Для последующей сверки можно использовать USDA FoodData Central: https://fdc.nal.usda.gov/. Для фактического меню значения следует заменить данными с этикеток используемых поставщиками продуктов или из их спецификаций.

## Метод расчёта

1. Для каждого ингредиента берётся КБЖУ на 100 г.
2. Показатели умножаются на количество граммов из ТТК.
3. Для соусов, риса, заправок и теста сначала рассчитывается отдельная заготовка, затем её КБЖУ включается в блюдо как вложенный компонент.
4. КБЖУ на порцию — сумма макронутриентов всех компонентов. КБЖУ на 100 г — эта сумма, делённая на выход готового блюда.
5. Для пиццы выбирается размер и тип теста. Масса теста берётся из переданной ТТК: 25 см пышное — 280 г, 35 см пышное — 480 г, 25 см тонкое — 200 г, 35 см тонкое — 280 г.

Для пицц размер в опции меню (25/35 см) сопоставляется с размером M/B из ТТК, а тип теста определяет граммовку тестовой заготовки. Масса готового изделия для расчёта на 100 г берётся из выхода M/B в ТТК. Это намеренно имеет приоритет над весом в текущей опции каталога: в каталоге и ТТК встречаются расхождения, которые нужно сверить отдельно.

## Допущения

- 1 литр оливкового масла для замеса теста принят за 910 г (приблизительная плотность 0,91 г/мл).
- Один лист нори принят за 2,5 г, так как в ТТК указаны доли листа, а не граммы.
- Для маринованной и копчёной курицы, сметаны, майонеза, отдельных соусов и других продуктов без этикетки использованы усреднённые оценки.
- Для суши-риса использована полная заготовка: 3000 г сухого риса, 3100 г воды и 900 г заправки; заправка считается из рисового уксуса, сахара и соли.
- Омлет рассчитывается по указанным ингредиентам, но нормируется на заявленный выход 65 г.
- Микрозелень и декор без указанного веса в расчёт не включаются.
- В рецептуре красного соуса сохранены 100 г соли из переданной ТТК. Соль не добавляет КБЖУ, но входит в заявленную массу заготовки.

## Неполные и несопоставленные позиции

- В рецептуре соуса для запекания указан «соус калиний», но его состав и пищевая ценность не раскрыты. Для роллов, в составе которых есть этот соус, полный результат намеренно не выводится. Нужно уточнить название, состав или прислать этикетку.
- Для «Ветчина-салями» и сетов в переданном наборе нет отдельных ТТК. Калькулятор не подставляет вместо них выдуманные рецептуры.
- Позиция каталога «Овощная» сейчас имеет описание с песто, баклажаном и цукини, тогда как переданная ТТК содержит красный соус, шпинат, перец, черри, брокколи и укроп. В расчёте используется ТТК; её нужно сверить с фактической рецептурой позиции.
- «Сырная» в каталоге сопоставлена с трёхсырной ТТК (моцарелла, чеддер, камамбер). В ТТК есть также отдельная «С сыром» без камамбера, но отдельной позиции каталога для неё не найдено.
- В некоторых роллах масса в ТТК отличается от массы, отображаемой в текущем меню. Для этих роллов выход из ТТК используется как масса порции.

## Проверка перед использованием

Перед публикацией нужно визуально проверить КБЖУ в карточках и увеличенном просмотре, переключение четырёх вариантов пиццы, роллы с полным составом и корректное сообщение для неполных рецептур. До получения этикеток поставщиков результат должен оставаться помеченным как оценочный.
